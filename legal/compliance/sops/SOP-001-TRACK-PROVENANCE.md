# SOP-001 — Track Provenance File

Open a dossier at first prompt or first lyric draft. Close it before distributor submission.

1. Create `catalog/songs/<slug>/` in GitHub and `03_RIGHTS_AND_PROVENANCE/tracks/<slug>/` in Drive.
2. Copy TRACK-DOSSIER and HUMAN-AUTHORSHIP-ATTESTATION.
3. Deposit lyric drafts, style/structure inputs, partial lyrics sent to the model, Suno URLs for rejected takes and the selected master, eval scores, artwork source.
4. Fill authorship-log fields. Leave unknowns explicit.
5. Classify experiment | candidate | canon. Classification is not clearance.
6. Run SOP-002 and SOP-005 before upload.
