# Paperwork Checklist

## A. Generator (Suno) — per released track
- [ ] Song URL and ID
- [ ] Parent/remix URL
- [ ] Creation timestamp
- [ ] Pro/Premier screenshot covering that date
- [ ] Invoice covering that date
- [ ] Download proof / master checksum
- [ ] Terms snapshot

## B. Human authorship — per released track
- [ ] First lyric draft
- [ ] Partial-page or framework text fed to the model
- [ ] Style/structure notes
- [ ] Edit history
- [ ] Rejected generation URLs
- [ ] Completed TRACK-DOSSIER
- [ ] Signed HUMAN-AUTHORSHIP-ATTESTATION

## C. Distributor — per release
- [ ] RouteNote submission ID
- [ ] Destination store list
- [ ] Moderation emails
- [ ] Disclosure answers as submitted
- [ ] Artwork as uploaded
- [ ] Metadata export

## D. Optional filings (only after A–C)
- [ ] USCO Standard Application packet
- [ ] PRO work registration limited to human-authored share
- [ ] MLC claim only if a copyright owner exists
