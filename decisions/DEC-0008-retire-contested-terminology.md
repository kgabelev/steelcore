# DEC-0008 — Retire Contested Terminology From Forward Use

- **Status:** Accepted
- **Date:** 2026-08-06
- **Decision owner:** Kirill Gabelev
- **Scope:** Steel and Alma & Steel catalog, identity, prompts, social content, metadata, campaigns, and release materials

## Context

Existing experiments contain the term **Gypsy** in working titles, lyrics, and prompts. The musical intent is flamenco-inspired Spanish nylon-string guitar combined with modern trap. The contested term is not necessary to preserve that sound and creates avoidable cultural, reputational, and possible trademark confusion.

The project also previously considered describing Steel as autonomous. That wording is inaccurate for the current process and conflicts with the project's need to document human creative direction and control.

## Decision

1. Retire **Gypsy**, **Gipsy**, **Gypsy King**, named-act emulation references, and materially similar identity claims from all forward-facing use.
2. Preserve historical prompts and lyrics verbatim in evidence records, clearly marked deprecated and non-reusable.
3. Create separate normalized prompts and release-ready lyric/title replacements.
4. Use **Golden Strings With The Trap** as the default replacement working title for **Gypsy Strings With The Trap**, pending final creative approval and ordinary title/trademark clearance.
5. Replace the chorus phrase **Gypsy strings with the trap** with **Golden strings with the trap** in release-candidate lyrics while keeping the original line in historical evidence.
6. Classify Steel as:

   > AI-native virtual recording artist; human-directed, human-in-the-loop production.

## Consequences

- The music, arrangement, energy, guitar vocabulary, and production direction remain intact.
- Existing evidence is not falsified or rewritten.
- Release candidates require a clean normalized version before clearance.
- Automated checks will prevent prohibited terminology from entering forward-facing project areas.

## Required follow-through

- Apply the replacement map to every registered track and prompt.
- Mark all raw evidence as historical/deprecated where applicable.
- Update social, persona, biography, and disclosure documents.
- Run the terminology scanner before merge and before release clearance.
