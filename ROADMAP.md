# Steelcore Roadmap

## M0 — AI Resource Control Plane

**Status:** Complete

**Outcome:** Model routing, budgets, quota evidence, parallel-agent limits, build history, and automated validation exist on `main`.

---

## M1 — Canonical Project Foundation

**Status:** In progress

**Purpose:** Give every human and agent the same product definition, decisions, ownership map, and next milestone.

**Exit criteria:**

- project context, current state, roadmap, decisions, agent contract, handoff template, and execution ledger are merged;
- first vertical slice is named and bounded;
- approval and permission boundaries are explicit;
- future workstreams can be isolated without file collisions.

---

## M2 — Canonical Source Import and Provenance

**Status:** Next

**Purpose:** Move existing lyrics, prompts, artwork, research, legal material, and Suno experiment records into the canonical repository without confusing raw evidence with approved canon.

**Parallel workstreams:**

1. **Creative catalog import** — songs, lyrics, prompts, production notes, artwork references.
2. **Research import** — legal, platform, industry, cultural, and music-theory sources with source register.
3. **Provenance framework** — authorship logs, AI-tool records, rights status, approval state, and release state.

**Exit criteria:**

- all known source sets are inventoried;
- originals are preserved;
- every imported item is classified as canon, candidate, experiment, evidence, or unresolved;
- provenance and missing-data flags exist;
- no source is silently rewritten during import.

---

## M3 — Steel Canon, Memory, and Evals

**Status:** Blocked by M2

**Parallel workstreams:**

1. **Artist canon** — persona, backstory, values, voice, visual identity, cultural grounding.
2. **Creative memory** — episodic, semantic, preference, decision, and artifact memory with promotion rules.
3. **Evaluation system** — trap-flamenco identity, lyrical quality, flow, originality, persona consistency, commercial strength, and provenance compliance.
4. **Dual creative system** — experimental critic plus mainstream hitmaker synthesis.

**Exit criteria:** Approved artist-bible baseline, memory contracts, retrieval tests, and a versioned eval suite.

---

## M4 — Steel Creative Session Vertical Slice

**Status:** Blocked by M3 and owner approval of D-006

**Purpose:** Prove Steel can create, criticize, improve, approve, and remember one real creative artifact end to end.

**Acceptance criteria:**

1. accepts a clear creative brief;
2. retrieves only relevant approved canon and memory;
3. produces multiple candidates without copying source artists;
4. returns separate critic and hitmaker evaluations;
5. synthesizes a ranked recommendation with reasons;
6. requires human approval before canon promotion;
7. stores approved output, rejected variants, scores, feedback, provenance, model usage, and cost;
8. can reproduce the session record from repository data.

---

## M5 — Buzz / ACP Integration

**Status:** Blocked by M4

**Purpose:** Make the proven Steel Creative Session available in Buzz with explicit identity, permissions, channels, audit logs, and safe tool boundaries.

**Exit criteria:** A Buzz user can run the vertical slice, review evidence, approve or reject output, and see the result persisted canonically.

---

## M6 — Production Hardening and Expansion

**Status:** Blocked by M5

Add observability, security review, backups, cost dashboards, regression evals, additional creative workflows, release operations, and carefully approved social capabilities.

## Critical Path

`M0 Control Plane → M1 Foundation → M2 Source Import → M3 Canon/Memory/Evals → M4 Creative Session → M5 Buzz → M6 Production`
